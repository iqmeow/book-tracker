Описание программы
Book Tracker - это графическое приложение для учета прочитанных книг. Программа позволяет:
- Добавлять книги с указанием названия, автора, жанра и количества страниц
- Просматривать список всех книг в удобной таблице
- Фильтровать книги по жанру и количеству страниц
- Сохранять и загружать данные в формате JSON
- Автоматическое сохранение данных при каждом изменении
- Удалять книги из списка

Требования
- Python 3.7 или выше
- Библиотека tkinter (входит в стандартную установку Python)
